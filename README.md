# 🚀 AI-Powered Public Grievance Management System

An intelligent full-stack grievance management platform built using the **MERN Stack**, **FastAPI**, **LangChain**, **Redis**, and **Docker**. The platform enables citizens to register complaints, track their status, while administrators efficiently manage grievances. An integrated AI chatbot provides instant assistance using Retrieval-Augmented Generation (RAG).

---

## ✨ Features

### 👤 User
- User Registration & Login (JWT Authentication)
- Lodge Public Grievances
- View, Update and Delete Own Complaints
- Complaint Tracking Dashboard
- AI-powered Grievance Assistant
- Responsive UI

### 🛡️ Admin
- View All Grievances
- Update Complaint Status
- Pagination Support
- Redis Cached Dashboard
- View Complaints by Status

---

## 🤖 AI Chatbot

Built using **LangChain + ChromaDB + HuggingFace Embeddings + Mistral AI**

Features

- Retrieval-Augmented Generation (RAG)
- Semantic Search
- Chroma Vector Database
- PDF Knowledge Base
- Context-aware Responses

---

## ⚡ Redis Caching

Implemented Redis to reduce unnecessary database queries.

Cached APIs

- Admin Dashboard Grievances
- User Grievance History

Features

- Automatic Cache Invalidation
- Configurable TTL
- Faster API Response
- Reduced MongoDB Load
